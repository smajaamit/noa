# Web Interface Guidelines
Before each review, consult the latest Vercel Web Interface Guidelines:
https://raw.githubusercontent.com/vercel-labs/web-interface-guidelines/main/command.md

Review the requested web files against all current rules. Prioritize accessibility, semantics, responsive behavior, touch usability, typography, performance, motion, focus states, reduced motion, safe areas and layout stability. Report concrete file/line findings, then fix them when implementation is requested.
