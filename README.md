# Noa ♥ 25

A private birthday experience built for Noa.

## Experience
- Mobile-first, RTL Hebrew layout
- Full-screen photographic opening
- Relationship timeline
- Responsive memory gallery
- Playful birthday section
- Live countdown to 09.09.2027
- Personal letter
- Subtle scroll animation with reduced-motion support
- Lazy-loaded images and graceful image fallback

## Structure
```
/
├── index.html
├── images/
└── .github/workflows/pages.yml
```

## Publishing
The site is prepared for GitHub Pages. Once the repository is public, enable **Settings → Pages → Source: GitHub Actions**. The deployment workflow will publish the current `main` branch.

Expected project URL after Pages is enabled:
`https://smajaamit.github.io/noa/`
