# UI/UX Pro Max
Apply this skill whenever a task changes how a feature looks, feels, moves, or is interacted with.

## Priority
1. Accessibility: WCAG contrast, alt text, keyboard, focus, semantic structure, reduced motion.
2. Touch & interaction: minimum 44x44 touch targets, 8px spacing, tap feedback, no hover-only interactions.
3. Performance: optimized responsive images, lazy loading below fold, reserve dimensions, avoid layout shift.
4. Style: consistent visual language, no decorative clutter, one primary action, consistent icons/elevation.
5. Responsive layout: mobile-first, no horizontal scroll, readable measures, safe areas, 4/8px spacing rhythm.
6. Typography/color: body >=16px mobile, 1.5-1.75 line-height, accessible contrast, semantic tokens.
7. Motion: 150-300ms micro-interactions, transform/opacity, motion must convey meaning, respect reduced-motion.
8. Feedback: clear state changes and progressive disclosure.
9. Navigation: predictable and minimal.

## Workflow
For every substantial UI task:
- Analyze product type, audience, context, tone and stack.
- Establish a coherent design system before implementation.
- Implement mobile-first.
- Run a final UX/a11y/performance review.
- Test at 375px, larger phone, desktop and landscape.
- Ensure all interactive targets >=44px, visible focus, semantic labels, no layout shifts.
- Prefer content-first immersive storytelling where appropriate.
